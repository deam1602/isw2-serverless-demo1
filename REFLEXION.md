¿Qué tipo de error evita el CI?
EL CI evita errores de regresión, es decir, romper algo que ya funcionaba, junto con los fallos de contrato. Esto lo realiza al momento de subir nuevos cambios, ya que realiza las pruebas automáticamente.

¿Qué tipo de error no evita?
No puede evitar errores de lógica del negocio que no fue comprendida correctamente o requisitos incompletos. Si se crea un test con una suposición falsa, este pasará aunque no sea lo que necesita el usuario.

¿Qué pasaría si un equipo ignora el CI?
Si se ignora, la calidad del software dependería de la memoria del dev, la cual puede fallar. Puede que se integre código roto y generar deuda técnica.
